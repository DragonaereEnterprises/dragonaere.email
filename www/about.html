This is the email server used by Andrew for all of his different stuff.

It is hosted using Proxmox Mail Gateway for Security and filtering. It uses widely used and battletested software under the hood to make sure all emails that are recieved are from legitimate sources.

Mail that passes the various tests are forwarded to a different mail server running Maddy which handles tasks like confirming the mailbox exists, IMAP and SMTP Submission. It also is the authentication source for both IMAP and SMTP.
